# VGRAPH
Интерактивный сайт для автоматической оптимизации укладки графов, использующий генетический алгоритм.

Основные возможности:
1. Загрузка файла с графом. 
При помощи последовательности нажатий на кнопки "работа с графом" --> "импорт графа" можно загрузить свой текстовый файл с расширением .dot, содержащий описание направленного графа (digraph) на языке DOT. 

Пример корректного входного файла:
digraph LogicCircuit {
	// Узел v1 передает сигнал в порт in1 узла v2
	v1 -> v2:in1;

	// Узел v1 также передает сигнал в порт in2 узла v2
	v1 -> v2:in2;

	// Передача сигнала без явного указания порта
	v2 -> v3;
}

При неявном указании портов, стрелки отрисовываются в середину основания вершины (перевернутого треугольника).

2. Интерактивная манипуляция.
Вы можете свободно перемещать элементы схемы по холсту, а также двигать сам холст.

3. "Умная" подсветка.
Для работы с перегруженными схемами реализована система фокусного выделения:

    Наведение на ребро: При наведении курсора на стрелку, она меняет цвет с черного на красный, а толщина линии увеличивается. Это позволяет мгновенно проследить путь сигнала от входа к выходу, даже если схема содержит десятки пересечений.

4. Настройка весов оптимизации.

В верхей части страницы сайта есть панель, на которой доступны три ключевых параметра, влияющих на итоговый вид схемы:

    Коэффициент A : Отвечает за минимизацию пересечений линий друг с другом.

    Коэффициент B : Предотвращает наложение логических блоков друг на друга.

    Коэффициент C : Исключает прохождение линий связи сквозь тела элементов.

Значения коэффициентов можно менять при помощи ползунков, либо вводить их вручную. 

ВАЖНО: нельзя задать весовым коэффициентам значения <=0. 

5. Оптимизация укладки.
При помощи последовательности нажатий на кнопки "работа с графом" --> "оптимизировать укладку" можно автоматически улучшить внешний вид графа. Процесс оптимизации анимирован и через консоль разработчика в браузере можно наблюдать за изменениями значений общей ошибки по мере работы генетического алгоритма. 

ВАЖНО: 
 -- пользовательские манипуляции с элементами графа НИКАК не влияют на его укладку во время работы алгоритма оптимизации.
 -- алгоритму необходимо несколько минут для выполнения своей работы.
 -- алгоритм использует те значения весов, которые были введены ДО начала его работы. 

Советы:
 -- Если схема "запуталась", попробуйте немного раздвинуть узлы вручную — это поможет алгоритму выйти из локального минимума и найти более удачную позицию.

Готовая версия приложения находится на ветке `build`.

## Скачать и запустить
1. Скачать ZIP репозитория с ветки `build`.
2. Извлечь файлы
3. В папке `backend\dist` запустить app.exe
4. Дождаться пока запуститься сервер (консольное окно с сообщением * Running on http://127.0.0.1:5000)
5. В браузере выполнить: http://localhost:5000/
